| blue_state | +0.089 | +0.089 | +0.000 |
| red_state | -0.072 | -0.065 | +0.008 |

Max change: 0.018 — the blue/red CES shifts are stable; only the (definitionally residual) swing class moves, and the model-side state effects are near-null regardless, so the calibration conclusion does not depend on the borderline assignments.
